LLM做导航为什么总是"瞎走"？深大团队用世界模型破局

UNeMo通过多模态世界模型与分层预测反馈机制，让导航智能体不仅能"看到"当前环境，还能"预见"下一步场景，在未见环境中导航成功率达72.5%。AAAI 2026已中稿。

在迈向通用具身智能的进程中，视觉语言导航（VLN）领域存在一个核心矛盾：大语言模型擅长理解指令，却缺乏空间推理能力。现有方法让LLM处理"穿过客厅左转"这样的指令，但模型根本不知道"左转之后会看到什么"。

深圳大学李坚强教授团队联合北京理工莫斯科大学，提出了UNeMo框架，核心突破在于构建"多模态世界模型+分层预测反馈导航器"的双向协同架构，将视觉状态推理与导航决策深度绑定。

1. 问题背景：LLM导航的两大硬伤

当前LLM-based VLN方法（如NavGPT2）存在两个根本缺陷：

  • 推理局限于语言模态：LLM能理解自然语言指令的语义，但无法"想象"执行动作后会观测到什么视觉场景。这就像一个人闭着眼睛听导航指令，却看不到前方的路。
  • 推理与决策相互脱节：NavGPT2在训练导航策略时冻结了LLM推理模块，导致推理过程无法根据策略训练进度动态优化，两者形成"信息孤岛"。
传统方法的拓扑图只编码历史状态（去过哪里、看到了什么），而缺乏对未来状态的预测能力。这就像只看后视镜开车。

2. 方法论：两步实现"预见未来"

2.1 多模态世界模型 (Multimodal World Model, MWM)

MWM的核心任务是回答一个问题："如果我执行这个动作，接下来会看到什么？"

技术实现采用条件变分自编码器（CVAE）：

当前局部视觉特征 + 语言指令
↓
Cross-Attention编码器（3层）
↓
均值μ + 方差σ² → 重参数化采样
↓
MLP解码 → 预测的下一步视觉状态

为什么用CVAE而非简单的MLP？因为视觉状态具有内在不确定性——同一动作可能导致略有不同的观测，CVAE的潜变量空间可以捕捉这种分布特性。

2.2 分层预测反馈导航器 (Hierarchical Prediction-Feedback Navigator, HPFN)

HPFN采用"粗粒度决策→世界模型预测→细粒度决策"的闭环架构：

第一层决策
当前节点嵌入 V_t → FFN → 粗粒度动作 a'（选择最高分节点j）
MWM推理
预测执行a'后的视觉状态 Ŝ_{t+1}
特征融合
Cross-Attention将预测状态注入节点嵌入 → 增强表示 V'_t
第二层决策
V'_t → FFN → 细粒度动作 a''（最终执行）

这形成了双向促进机制：策略决策反馈优化世界模型的预测，世界模型的推理结果又持续优化导航策略。两者不再是"各干各的"，而是协同进化。

4. 消融实验：每个模块都不可或缺

论文通过消融实验验证了各组件的贡献：

配置 SR 说明
仅MWM（无HPFN） 71.5% 世界模型单独作为辅助分支
仅第一层动作 a' 72.1% 不用MWM预测
仅第二层动作 a'' 72.9% 整合MWM推理，最优
a' 和 a'' 联合学习 72.1% 反而下降
关键发现：让决策直接受益于世界模型预测，比简单的多任务学习更有效。世界模型不应是"旁观者"，要和决策深度绑定。

5. 对具身智能行业的启示

  • 世界模型与策略要联合优化：当前很多工作把世界模型当作独立的预训练组件（如Dreamer系列），与下游策略学习分离。UNeMo证明了协同进化的价值。
  • 从"理解指令"到"预见结果"：主流VLA方法（RT-2、OpenVLA等）本质上是在做"指令→动作"的映射，缺乏对动作后果的显式建模。UNeMo提供了一条思路：在决策回路中引入显式的状态预测。
  • 资源效率是落地关键：用更少参数实现更好效果，对边缘部署意义重大。传统规划算法+轻量世界模型的组合，可能是工业机器人的务实路线。
  • 长程任务需要前瞻能力：对于需要多步规划的场景（如仓储物流、服务机器人），"看得更远"的能力至关重要。

6. 局限与展望

  • 仿真到现实的鸿沟：论文使用Matterport3D真实数据缩小了视觉gap，但尚未在物理机器人上验证。
  • 单步预测的局限：目前只预测下一步状态，多步rollout可能带来更大收益。
  • 指令粒度依赖：在REVERIE（粗粒度指令）上SPL略有下降，说明探索行为增加了路径长度。
